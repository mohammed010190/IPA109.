# IPA109 — نسخة أولية حقيقية لتطبيق آيفون

## ما الذي يعمل حاليًا؟

- تطبيق iPhone أصلي بواجهة عربية مبنية بـSwiftUI.
- إنشاء تطبيقات بسيطة ومتوسطة بالذكاء الاصطناعي باستخدام Gemini API المجاني ضمن حدوده.
- إذا طلبت من IPA109 أن ينشئ تطبيقًا بالإنجليزية، فإن النصوص داخل التطبيق الناتج تكون بالإنجليزية. واجهة IPA109 نفسها عربية.
- تعديل نفس المشروع بالمحادثة، حفظ المشاريع محليًا، ومعاينة التطبيق على الآيفون.
- تحويل التطبيق الناتج إلى ملف IPA **غير موقّع** عبر GitHub Actions، ثم تثبيته عبر SideStore.
- بعد التثبيت والتهيئة الأولى، يعمل من الهاتف بدون تشغيل الكمبيوتر.

## قيود النسخة الأولية (مهم)

تطبيقات المستخدم التي يولّدها Gemini هنا عبارة عن ملفات HTML/CSS/JavaScript تعمل داخل تطبيق iOS باستخدام WKWebView. هذا يتيح تطبيقات مثل الملاحظات والقوائم والحاسبات والألعاب البسيطة. لا ينشئ أي كود Swift عشوائي ولا يضمن وظائف iOS الأصلية مثل iCloud، الإشعارات، أو الوصول للأجهزة الطرفية. هذه تحتاج تطويرًا مستقلًا. ليس كل طلب سينجح من أول محاولة، ولا يوجد ضمان لاستخدام مجاني غير محدود لواجهة Gemini.

## إعداد المرة الأولى من الكمبيوتر (Windows أو Mac)

1. أنشئ حساب GitHub إن لم يكن لديك.
2. أنشئ مستودعًا عامًا جديدًا مثل `IPA109` (إن أردت المجانية على macOS runner). **تنبيه: جعل المستودع عامًا يعني أن أكواد التطبيقات المنشأة ستصبح عامة عند تصديرها. لا تستخدم أسرارًا أو بيانات شخصية في التطبيقات التي سترفعها إليه.**
3. ارفع جميع الملفات **كما هي بالمجلدات** إلى المستودع، بما في ذلك مجلد `.github` المخفي وملفات `IPA109` و`GeneratedApp`.
4. من GitHub افتح `Actions` ثم `Build IPA109 for SideStore` ثم `Run workflow`.
5. إذا اكتمل البناء، افتح `Releases` ونزّل ملف `IPA109.ipa` من آخر إصدار.
6. افتح الملف على الآيفون في SideStore وثبّت IPA109. قد تحتاج إلى تحديث/إعادة توقيعه وفقًا لسياسة SideStore وحساب Apple.
7. افتح https://aistudio.google.com/api-keys وأنشئ مفتاح Gemini API، ثم أدخله داخل `IPA109 > الإعدادات`.
8. من GitHub: Settings > Developer settings > Personal access tokens > Fine-grained tokens. أنشئ رمزًا بأضيق صلاحيات ممكنة لمستودع IPA109 فقط: **Contents (Read and write)** و**Actions (Read and write)**. أدخله في إعدادات IPA109 على الآيفون مع اسم الحساب واسم المستودع والفرع الأساسي `main`.
9. اكتب طلبك في شاشة الإنشاء. مثال: `اصنع تطبيق ملاحظات، جميع الصفحات والأزرار فيه باللغة الإنجليزية`.
10. بعد اكتمال الرد، افتح `معاينة التطبيق`. ولتصديره اختر `تصدير IPA` ثم `ابدأ بناء IPA`، ثم `تحقق من جاهزية IPA` بعد اكتمال تنفيذ GitHub Actions. سيظهر رابط تنزيل الملف عند صدور إصدار GitHub.

## الأمان والخصوصية

- تخزَّن مفاتيح Gemini وGitHub داخل Keychain الخاص بالآيفون (لا تُرفع ضمن كود المشروع).
- عند استخدام Gemini API، تُرسل أوامرك ومحتوى التطبيق الحالي إلى Google لتوليد التعديل.
- عند الضغط على تصدير، يُرسل HTML الخاص بالتطبيق إلى مستودع GitHub الذي أدخلته. إذا كان عامًا فالمحتوى عام. استخدم مستودعًا خاصًا إذا كانت الخصوصية أولى لديك، مع الانتباه لحدود/تكلفة GitHub Actions للمستودعات الخاصة.
- احتفظ برمز GitHub سرّيًا، ولا تشاركه في محادثة أو لقطات الشاشة.
- HTML الذي يولده النموذج قد يحتوي على أخطاء أو روابط غير مرغوبة؛ راجع الناتج قبل استخدامه على بيانات حقيقية.

## تقنية المشروع

- `IPA109/` المصدر الأصلي للمصنع نفسه (SwiftUI / iOS 17+).
- `GeneratedApp/` قالب تطبيق iOS الحقيقي الذي يضم HTML الذي تنشئه.
- `.github/workflows/build-ipa109.yml` إصدار المصنع نفسه.
- `.github/workflows/build-generated.yml` إصدار التطبيقات المنشأة.

**الحالة:** المصدر مكتمل كنسخة أولية لكنه غير مجرَّب ببناء Xcode فعلي داخل هذه البيئة؛ ينبغي التحقق من أول تشغيل GitHub Actions وإصلاح أي أخطاء تظهر في سجل البناء.
